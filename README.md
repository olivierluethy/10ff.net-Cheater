# 10ff.net-Cheater  

## Overview  
**10ff.net-Cheater** is a browser extension designed to enhance your gaming experience on the 10ff.net platform. This extension automates certain tasks, allowing you to focus on gameplay while it handles repetitive actions for you.  

---

## Features  
- **Task Automation**: Automates gameplay actions based on specific conditions. 
- **Customization Options**: Customizable settings to adjust the speed and behavior of the automation.
- **Efficiency Boost**: User-friendly interface for easy configuration.

---

## Installation  

### Chrome  
1. Clone or download the repository.  
2. Open Chrome and go to `chrome://extensions/`.  
3. Enable **Developer mode** in the top-right corner.  
4. Click **Load unpacked** and select the folder containing this extension.  
5. The extension will now appear in your browser's toolbar.  

### Firefox  
1. Clone or download the repository.  
2. Open Firefox and go to `about:debugging#/runtime/this-firefox`.  
3. Click **Load Temporary Add-on** and select the `manifest.json` file from the extension folder.  
4. The extension will be active until the browser is closed.  

---

## Usage  
1. Install the extension following the instructions above.  
2. Open the 10ff.net platform in your browser.  
3. Use the extension's controls or automated features as needed to enhance your experience.
